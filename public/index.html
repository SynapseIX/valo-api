Developer docs

API reference

Base URL: https://valo-api.synapseix.pro. Send your key as Authorization: Bearer val_... over HTTPS.

          curl -H 'Authorization: Bearer val_YOUR_KEY' \
            https://valo-api.synapseix.pro/v1/me
GET /v1/me

Linked Riot ID, PUUID, region, and sharing status.

GET /v1/matches

Official match history for the linked account.

GET /v1/matches/:matchId

Official match details, only when the linked player appears in that match.

GET /v1/rank

Official leaderboard tier, placement, and ranked rating if available. Other players get null values and availability: "unavailable_outside_leaderboard".

POST /v1/key/rotate

Issues a new API key and invalidates previous keys.

POST /v1/disconnect

Removes the linked account and invalidates its keys.

GET /health · GET /legal

Public health check and legal notice; neither requires an API key.

Example rank response

            {
              "riotId": "Example#NA1",
              "act": { "id": "act-uuid", "name": "ACT NAME" },
              "rank": null,
              "rr": null,
              "availability": "unavailable_outside_leaderboard",
              "source": "riot_official"
              }

Riot’s documented API does not offer current rank and RR for every player. This API cannot show a precise current RR outside the available leaderboard entries. Data may be delayed by Riot’s updates or rate limits.

Errors use {"error":{"code":"...","message":"..."}}. Common statuses: 400 invalid request, 401 invalid key, 403 consent or match restriction, 404 missing resource, 429 Riot rate limit, 502 Riot failure, 503 missing configuration. Transparency

Before you connect

Your API key gives its holder access to the linked account’s data through this service. The server stores Riot OAuth tokens to keep the account connected. Disconnect to delete local account data and invalidate your keys; you may separately withdraw Riot authorization in Riot account settings.

Do not publish your API key. Read our Privacy Policy and Terms of Use before connecting. We do not sell player data.
